# Build Your Own - Git

Git is fundamentally a content-addressable filesystem with a VCS (Verion Control System) user interface layered on top.

This repository (inspired by [Coding Challenges](https://codingchallenges.fyi/challenges/challenge-git/)) explores [Git internals](https://git-scm.com/book/en/v2) by implementing a custom Git client from scratch — rebuilding core features step by step to gain a deep understanding of how Git works under the hood.
